# 프로젝트 사진 넣는 법

## 1. 이 폴더에 이미지 파일을 넣습니다

지원 형식: `png` `jpg` `jpeg` `webp` `avif` `svg`

파일명은 어떤 프로젝트인지 알아보기 쉽게 짓습니다.

```
licar-demo.png
licar-robot.jpg
smart-window-ui.png
```

## 2. `src/data/profile.ts` 의 해당 프로젝트에 `images` 를 추가합니다

```ts
{
  id: 1,
  title: 'Licar',
  // ...기존 내용...
  images: [
    { file: 'licar-demo.png', alt: '알약을 싣고 병원 복도를 주행하는 로봇' },
    { file: 'licar-robot.jpg', alt: '상자 문이 열린 로봇 본체 클로즈업' },
  ],
}
```

- `file` 은 **이 폴더 안의 파일명만** 적습니다 (경로 없이).
- `alt` 는 사진에 무엇이 있는지 적습니다. 화면에 캡션으로도 보이고,
  스크린리더 사용자와 이미지가 안 뜰 때도 이 글이 대신 읽힙니다.
- **첫 번째 이미지가 카드 썸네일**로 쓰입니다. 가장 잘 나온 걸 맨 앞에 두세요.
- `images` 를 안 적으면 그 프로젝트는 지금처럼 글자만 나옵니다.

## 3. 주의할 점

- 파일명을 잘못 적으면 그 이미지만 빠지고, 개발 서버 콘솔에 어떤 파일을 못 찾았는지 경고가 뜹니다.
- **카드 썸네일은 16:9로 잘립니다**(`object-cover`). 중요한 내용이 가장자리에 있으면 잘릴 수 있습니다.
  상세 창에서는 잘리지 않고 전체가 보입니다.
- 사진은 그대로 저장소에 올라가므로, 한 장에 **1MB 이하**를 권합니다.
  스크린샷은 `png`, 실물 사진은 `jpg` 나 `webp` 가 용량이 작습니다.
- 사람 얼굴이나 사내 화면처럼 **공개해도 되는지 확인이 필요한 사진은 넣기 전에 한 번 더 확인**하세요.
  이 저장소는 공개돼 있고, 한 번 올리면 깃 이력에 남습니다.
